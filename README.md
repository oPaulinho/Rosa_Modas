# 🌐 Projeto Extensionista – Site Responsivo para Comércio Local

Este projeto foi desenvolvido como parte da **Atividade Extensionista II (Uninter)** com foco em **Tecnologia Aplicada à Inclusão Digital**.  
O objetivo principal é apoiar o **pequeno comércio familiar** através da criação de um **site responsivo**, simples e acessível, permitindo maior presença digital e contato com clientes.

## 🔗 Acesse o projeto

Você pode visualizar o site publicado em:  
👉 (https://rosa-modas.vercel.app)

## 🛠️ Tecnologias utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (básico)**  
- **Metodologia Mobile-First**  
- **Media Queries** para responsividade  
- **Hospedagem gratuita na Vercel**

## 📚 Etapas do desenvolvimento

1. **Levantamento de necessidades** – coleta de informações com a comerciante.  
2. **Planejamento** – definição da estrutura das páginas e acessibilidade.  
3. **Desenvolvimento** – codificação do site responsivo.  
4. **Testes e validação** – ajustes em diferentes dispositivos e navegadores.  
5. **Hospedagem** – publicação no Vercel com QR Code.  
6. **Capacitação** – explicação prática para uso da ferramenta pela comerciante.  

## 🎯 Resultados

- Site responsivo publicado com informações da loja (produtos, serviços, contato e localização).  
- Inclusão digital do pequeno comércio familiar.  
- Facilitação do contato com clientes via **WhatsApp**.  
- Compartilhamento rápido por meio de **QR Code**.
