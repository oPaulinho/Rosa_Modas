# Rosa Modas & Universo Rosa

Projeto de extensão da Uninter — tecnologia aplicada à inclusão digital para um pequeno comércio familiar.

Dois sites, um painel administrativo e uma API REST:

- **Rosa Modas** — catálogo de roupas (produtos com emoji, preço, status)
- **Universo Rosa** — espaço espiritual (serviços com emoji, agendamento presencial/online, WhatsApp)
- **Painel** — gerencia produtos, serviços, promoções, agenda, configurações e textos do site

## Tecnologias

- Frontend: HTML5, CSS3, JavaScript (ES Modules), Google Fonts
- Backend: Java 17 + Spring Boot (REST API), MySQL
- Hospedagem: Vercel (sites estáticos) + Render (API via Docker)
- Notificações: links `wa.me` para WhatsApp





## Contexto

Feito pra Atividade Extensionista da Uninter, uso real no comércio da família.
